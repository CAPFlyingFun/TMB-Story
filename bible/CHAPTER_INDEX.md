# Chapter Index

One row per **approved** chapter, appended in order, drawn from that chapter's
frontmatter. Append-only: a row is edited only if Joshua changes the approved
chapter it describes, and that edit is named in the commit. To orient on any
stretch of the series, read the rows around it and open only the chapters they
point at.

Conventions: `Ch` is the four-digit chapter number. `Clock` is `O` (outside world)
or `I` (island). `Mysteries` lists ids from `MYSTERIES.md` as `+M##` introduced,
`~M##` advanced, `=M##` answered. `Ending` is the rotating ending type. `Rev`/`Audio`
are the two status fields. Keep cells short; the chapter file holds the detail.
